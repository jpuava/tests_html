About this project

How this site was built

A learning project built from scratch with plain HTML, CSS, and JavaScript. No frameworks, no build tools — just the three core languages of the web.

HTML

Defines the structure: headings, sections, forms, navigation, and footer.

CSS

Handles all visual design: colors, typography, layout, and responsiveness.

JavaScript

Adds interactivity: form validation, DOM updates, and event handling.

Key concepts practiced

  • Separating HTML, CSS, and JS into their own files
  • Linking a CSS stylesheet from an HTML page
  • Connecting a JS file to HTML with a script tag
  • Client-side form validation with error messages
  • Multi-page navigation with anchor links
  • Deploying a static site with GitHub Pages
