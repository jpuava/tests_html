Starter Website Project

Files
- index.html: page structure
- styles.css: all page styling
- script.js: interactivity

How to run
1. Open index.html in your browser.
2. Keep your editor and browser side by side.
3. After each change, refresh the browser.

Beginner practice tasks
1. Change the main heading text in index.html.
2. Change one color variable in styles.css (for example --accent).
3. Add a fourth card in the card-grid section.
4. In script.js, change the button behavior to show a custom message.

What to do when the site is ready
1. Create a GitHub repository and push your files.
2. Enable GitHub Pages in repository settings.
3. Your site will be available at:
	https://<your-github-username>.github.io/<repository-name>/

Optional next steps
- Add a contact form section.
- Add a Projects section with links.
- Add a dark mode toggle in script.js.
